# Autism Support tools

Autism Support tools is a local-first collection of learning, communication, and play-based support apps for autistic children and caregivers. The apps focus on predictable screens, low-distraction layouts, clear choices, gentle feedback, and offline privacy.

The goal is simple: help children learn while playing, communicate with visual supports, and stay engaged without overwhelming interaction patterns.

## Main Tools

| Tool | Location | Purpose |
|---|---|---|
| BrightSteps Puzzle Time | `autism-support-tools/brightsteps/` | Educational puzzle app for Android and Windows with calm feedback, adaptive local progress, and multiple puzzle types. |
| BrightVoice AAC | `autism-support-tools/brightvoice-aac/` | Offline AAC starter board for Windows with visual communication cards, sentence builder, core words, and caregiver personalization. |
| Digital Puzzle | `autism-support-tools/digitial-puzzle/` | Legacy browser puzzle moved under the Autism Support tools collection as a play-and-learning activity. |

## Design Principles

- Low-distraction, predictable screens
- Clear choices and large touch-friendly targets
- Gentle feedback instead of harsh error cues
- Offline-first behavior where practical
- Local device storage for child settings and progress
- No ads, analytics, login, or external JavaScript in the support apps

## Tested Focus

BrightSteps and BrightVoice were designed and locally tested for autistic children and children who benefit from visual structure, calm pacing, and repeatable learning routines. These tools are not medical advice and do not replace guidance from caregivers, educators, therapists, or speech-language professionals.
