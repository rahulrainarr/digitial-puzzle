BRIGHTSTEPS PUZZLE TIME - WINDOWS / LAPTOP APP
==============================================

HOW TO START
------------
Double-click:
  BrightSteps-Puzzle-Windows.exe

The app opens in your default browser and works offline. No login is required.
The .cmd launcher is included as a fallback.

FEATURES
--------
- First-use setup for name, age, and puzzle difficulty
- Puzzle menu with Odd One Out, Pattern Path, Memory Match, Adding Up,
  Word Links, Word Search, Mini Crossword, Category Match, Daily Routine,
  Feelings Clues, Compare Numbers, Shape Sorter, Bridges, Loopy, Suguru,
  and Fillomino
- Easy, medium, challenge, and expert content
- The five newest logic puzzles include 50 generated variants per difficulty
  tier, for 200 variants per new puzzle type
- Automatic move to the next puzzle after a correct answer
- Local response tracking with suggested next activities
- Optional gradual automatic difficulty adjustment with caregiver control
- Calm, positive encouragement after attempts and completions
- Stars earned for completed puzzles
- Optional spoken encouragement and quiet mode
- Local settings saved only on the laptop

DESIGN NOTE
-----------
BrightSteps is designed as an engagement-friendly starter activity for autistic
children and other children who benefit from predictable screens, clear choices,
gentle feedback, and a low-distraction mode. It is not medical advice or a
substitute for individualized guidance from the child's caregivers, educators,
or therapists.
