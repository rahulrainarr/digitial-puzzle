# BrightSteps Puzzle Time

BrightSteps is an offline educational puzzle app designed for autistic children and other children who benefit from predictable screens, clear choices, and gentle feedback.

This repository folder contains:

- `windows/` - offline Windows/browser version and lightweight launcher
- `android/` - Android WebView source files and install notes
- `release/` - packaged APK and ZIP files for sharing/installing

## Puzzle Coverage

BrightSteps includes Odd One Out, Pattern Path, Memory Match, Adding Up, Word Links, Word Search, Mini Crossword, Category Match, Daily Routine, Feelings Clues, Compare Numbers, Shape Sorter, Bridges, Loopy, Suguru, and Fillomino.

The newest logic puzzles include 50 generated variants per difficulty tier across Easy, Medium, Challenge, and Expert.

## Safety Notes

The Android APK is an offline WebView app with no Android permissions, no ads, no analytics, no login, and no external scripts. It is intended as an engagement-friendly starter activity, not medical advice.

For wider distribution, prefer Google Play or Firebase App Distribution over direct APK sharing.
