# Digital Puzzle

This is the legacy browser puzzle activity, now grouped under **Autism Support tools** as a simple play-and-learning exercise.

It demonstrates:

- Browser-based puzzle interaction
- Drag-and-drop style play
- Responsive static HTML/CSS/JavaScript structure
- A lightweight starting point for visual puzzle activities

This activity is less autism-specific than BrightSteps and BrightVoice, but it is retained here as a reusable play-based learning prototype.
