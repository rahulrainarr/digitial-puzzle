# Autism Support tools

This folder collects two local-first support apps for autistic children and caregivers. The tools are designed for predictable screens, clear choices, offline use, and gentle feedback.

## Included Apps

### BrightSteps Puzzle Time

Location: `brightsteps/`

BrightSteps is an educational puzzle app with low-distraction activities, adaptive local progress tracking, and Android/Windows builds.

Key points:

- Android package: `com.brightsteps.puzzletime`
- Android version: `1.0.2`
- Includes 16 puzzle and learning activity types
- Newer logic puzzles include 50 generated variants per difficulty tier
- Offline Android WebView app with no Android permissions
- Windows/browser version included

### Awaz / BrightVoice AAC Starter

Location: `awaz-brightvoice-aac/`

BrightVoice is an offline augmentative and alternative communication starter app for Windows laptops and touch devices. It supports visual communication, sentence building, quick core words, vocabulary categories, and caregiver personalization.

Included files:

- `index.html`
- `styles.css`
- `app.js`
- `BrightVoice-AAC-Windows.exe`
- `Start-BrightVoice-AAC.cmd`
- `README.txt`

## Security And Privacy

- Apps are local-first and offline.
- No analytics, ads, login, or external JavaScript are included in the app code.
- BrightSteps Android requests no Android permissions.
- Child profile/progress settings are stored locally on the device/browser.

## Note

These apps are engagement and communication support tools, not medical advice or substitutes for individualized guidance from caregivers, educators, therapists, or speech-language professionals.

Third-party Avaz brochure/PDF reference files from the local folder were not republished here.
